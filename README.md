# NeuroFarming website

Standalone marketing site for NeuroFarming (SMART ERA / Eight Bells).

## Open locally

```bash
cd C:\Users\a.ioannidis\Documents\neurofarming-website
python -m http.server 5175
```

Visit http://localhost:5175

## What’s in this version

- Higher-quality field-app screenshots (upscaled WebP from source PNGs)
- Olive-leaf capture composite in the phone viewport
- Dedicated **Admin web app** section with real dashboard screenshots:
  - Overview, observations, outbreak map
  - Continuous AI learning, users & roles, SMART ERA KPIs
- Brand-first grove hero, dual-phone showcase, contact CTA
- Soft parallax, scroll reveals, self-hosted fonts
