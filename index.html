In the handset

Built for the grove, not the office.

Offline-first capture queues the photo when signal drops, then syncs for higher-accuracy cloud diagnosis. On-device TensorFlow Lite covers the first pass without a network.

  • Works through patchy mobile coverage
  • Stores the photo until upload can finish
  • Keeps consent with every observation

Vision inference

Cloud intelligence, agronomist-ready.

BioCLIP-2 returns a label, confidence score, and recommendation text. Low-confidence or false-healthy cases can escalate for human review through continuous learning.

Operations console

Admin web app for cooperatives and agronomists.

NeuroFarming includes a browser-based admin dashboard — not just the field app. Operators manage users, review observations, watch outbreak hotspots, track SMART ERA KPIs, and steer continuous model learning from one console.

  • Overview — users, observations, feedback, telemetry, and API health at a glance
  • Observations — review farmer uploads and diagnosis outcomes
  • Outbreak map — Mallorca-centred hotspot monitoring for the pilot
  • Users & roles — activate accounts and promote farmers to agronomist or admin
  • KPIs — SMART ERA evidence metrics for consortium reporting
  • ML learning — label review, retraining signals, and continuous improvement
  • System ops — advisories, inference queue, API logs, and system messages
